# ☕ Café Central — Sistema de Pedidos

## 📌 Nombre del proyecto
cafe-central-app

## 📝 Descripción
Aplicación web para la cafetería "Café Central" que permite a los clientes consultar el menú, ver precios, registrarse y realizar pedidos desde su dispositivo móvil o computadora.

## ❓ Problema que resuelve
Facilita a los clientes conocer el menú y hacer pedidos sin necesidad de ir presencialmente al establecimiento.

## ✨ Funcionalidades principales
- Consulta del menú
- Visualización de precios
- Registro de clientes
- Selección de productos
- Creación de pedidos
- Consulta del estado del pedido
